Implementing Viafoura Ratings & Reviews

Implementation Guide
November 4, 2026 Technical Documentation

What is Viafoura Ratings & Reviews?

Viafoura Ratings & Reviews empowers your audience to provide feedback on products, services, recipes, and many more topics that foster trust and engagement. The widget visually displays ratings using a 5-star system, along with the numerical average and total number of ratings received.

Key Features

  • 5-star rating system - Industry-standard star ratings (1-5 stars)
  • Written reviews - Detailed feedback with text and rich formatting
  • Rating summary - Average rating and total count display
  • Helpful voting - Users can mark reviews as helpful
  • Sorting options - Most helpful, newest, highest rated, and more
  • Reply functionality - Authors can respond to reviews
  • Verified badges - Identify verified purchasers (optional)
  • Pagination - Configurable review loading

Ideal Use Cases

  • E-commerce products - Customer reviews on product pages
  • Recipe sites - User ratings and cooking feedback
  • Local businesses - Service provider ratings and testimonials
  • Entertainment content - Movies, TV shows, books, music reviews
  • Restaurant reviews - Dining experiences and menu items
  • Travel & hospitality - Hotel, destination, and tour reviews

Basic Implementation

The Ratings & Reviews feature uses two separate widgets that work together:

Step 1: Load the Viafoura SDK

<script async src="https://cdn.viafoura.net/entry/index.js"></script>

Step 2: Add the Rating Summary widget

<div class="viafoura">
  <vf-rating></vf-rating>
</div>

Step 3: Add the Reviews List widget

<div class="viafoura">
  <vf-livereviews></vf-livereviews>
</div>

Widget Components Explained

Rating Summary (vf-rating):

  • Displays the average star rating
  • Shows total number of ratings
  • Provides visual 5-star display
  • Often placed near product title or hero image

Review List (vf-livereviews):

  • Shows individual user reviews with full text
  • Includes star ratings per review
  • Enables sorting and filtering
  • Allows users to submit new reviews
  • Displays helpful vote counts

Container ID Setup

Each review container needs a unique container ID. You can set this in two ways:

Option 1: Meta tag (recommended)

<meta name="vf:container_id" content="P2001">

Option 2: Widget attribute

<vf-livereviews vf-container-id="P2001"></vf-livereviews>

Configuration Parameters

Customize the Reviews widget behavior with these parameters:

Parameter Default Description
limit 10 Initial reviews loaded (1-100)
pagination-limit 10 Reviews per "load more" click (1-100)
reply-limit 2 Initial replies shown per review (0-100)
pagination-reply-limit 10 Replies per "load more" click (1-100)
sort most_helpful Default sorting (see sorting options below)

Sorting Options

The sort parameter accepts these values:

  • most_helpful - Reviews with most helpful votes (default)
  • newest - Most recently posted reviews first
  • oldest - Oldest reviews first
  • top_rated - Highest star ratings first
  • lowest_rated - Lowest star ratings first
  • most_replies - Reviews with most discussion

Example with parameters:

<vf-livereviews
  limit="20"
  pagination-limit="15"
  sort="newest">
</vf-livereviews>

Rating Widget Parameters

The Rating Summary widget supports these parameters:

Parameter Default Description
vf-container-id - Links to specific review container
show-ratings true Controls visibility of rating counts

Reviews Without Ratings

Viafoura supports a "Reviews Without Ratings" feature that allows users to submit written feedback without mandatory star selection. This is a site-level configuration managed through the Admin portal.

When enabled:

  • Users can write reviews without selecting stars
  • Unrated reviews are excluded from average calculations
  • Useful for qualitative feedback collection

Required: Notification Tray

CRITICAL: The Ratings & Reviews widget requires the On-Site Notification Tray to be implemented on the page. The widget includes call-to-action buttons that rely on the notification tray for login/signup, posting, and reply functionality.

Failing to implement the Notification Tray will result in a broken user experience. Always include:

<vf-tray-trigger floating="true"></vf-tray-trigger>

Best Practices

  • Place the Rating Summary near the top of the page for visibility
  • Position the Review List below the main content
  • Use "most_helpful" sorting to surface quality reviews
  • Moderate reviews to maintain trust and authenticity
  • Enable verified purchase badges when applicable
  • Respond to negative reviews professionally
  • Encourage satisfied customers to leave reviews
  • Set appropriate pagination limits based on your traffic

SEO Benefits

User-generated reviews provide valuable SEO benefits:

  • Fresh, regularly updated content
  • Natural keyword usage from real customers
  • Increased time on page
  • Rich snippets with star ratings in search results (when properly configured)
  • Social proof signals for search engines
