Implementing Viafoura Live Q&A

Implementation Guide
November 4, 2026 Technical Documentation

What is Viafoura Live Q&A?

Viafoura Live Q&A (also called Live Questions) enables you to host real-time, moderated question-and-answer sessions directly on your site. It fosters dynamic, two-way engagement between your audience and featured hosts or experts, with questions appearing instantly without page refreshes.

Key Features

  • Real-time question submission - Audience can ask questions instantly
  • Community voting - Users upvote/downvote questions to surface the best ones
  • Reply functionality - Hosts and moderators can answer questions directly
  • Threaded discussions - Follow-up questions and replies create conversations
  • Moderation controls - Admins can approve, feature, or remove questions
  • Sticky header - Widget header remains visible when scrolling

Ideal Use Cases

  • Expert interviews - "Ask Me Anything" style sessions
  • Town halls - Community discussions with leadership
  • Product launches - Real-time Q&A about new features or products
  • Virtual events - Audience participation during online conferences
  • Panel discussions - Let the audience drive the conversation

Basic Implementation

The simplest way to add Live Q&A to your page requires just two steps:

Step 1: Load the Viafoura SDK

<script async src="https://cdn.viafoura.net/entry/index.js"></script>

Step 2: Add the widget

<div class="viafoura">
  <vf-livequestions></vf-livequestions>
</div>

Container ID Setup

Each Live Q&A needs a unique container ID to keep questions separate. You can set this in two ways:

Option 1: Meta tag (recommended)

<meta name="vf:container_id" content="P1003">

Option 2: Widget attribute

<vf-livequestions vf-container-id="P1003"></vf-livequestions>

Title Customization

The Live Q&A header can be customized or hidden using the title parameter:

Code Result
<vf-livequestions> Shows "Live Q&A" header (default)
<vf-livequestions title=""> Hides the header entirely
<vf-livequestions title="AMA"> Shows custom "AMA" text

Admin Configuration Requirements

IMPORTANT: A moderator or admin level user must load the page in order for the Live Q&A to be initialized and configured. This is a one-time setup requirement per container ID.

Without admin initialization, the widget will not function properly. Make sure an authorized user visits the page before the event begins.

Sticky Header Accommodation

The Live Q&A widget includes a sticky header that remains visible when scrolling through questions. If your site uses a sticky header, navigation bar, or other fixed element at the top of the page, you need to define reserved space to prevent overlap:

.viafoura {
  --reserved-space-top: 2rem;
}

/* Mobile adjustment */
@media (max-width: 480px) {
  .viafoura {
    --reserved-space-top: 1rem;
  }
}

Adjust the values to match your site's header height. This ensures the Live Q&A sticky header appears below your navigation.

How It Works

For audience members:

  1. Users must be logged in to submit questions (authentication required)
  2. Submit a question using the text input
  3. Vote on other users' questions with upvote/downvote buttons
  4. Questions with more votes rise to the top
  5. Reply to answers or other questions to create discussions

For moderators/hosts:

  1. View all submitted questions in real-time
  2. Answer questions directly in the widget
  3. Feature important questions to highlight them
  4. Remove inappropriate or duplicate questions
  5. Monitor engagement and participation metrics

Best Practices

  • Initialize the Live Q&A with an admin account before the event
  • Announce the Q&A session in advance to build audience anticipation
  • Set community guidelines for question submission
  • Have moderators pre-screen questions before hosts see them (optional)
  • Answer top-voted questions first to respect audience priorities
  • Keep a moderator actively monitoring during the session
  • Archive the Q&A session afterward as evergreen content
