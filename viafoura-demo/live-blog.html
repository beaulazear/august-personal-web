Implementing Viafoura Live Blog

Implementation Guide
November 4, 2026 Technical Documentation

What is Viafoura Live Blog?

Viafoura Live Blog is a real-time content publishing tool that allows journalists and moderators to provide continuous coverage of unfolding events. Updates appear automatically without requiring page refreshes, fostering two-way audience engagement as stories develop.

Key Features

  • Real-time updates - Posts appear instantly without page reload
  • Rich media support - Embed images, videos, and social media
  • Chronological display - Latest updates appear at the top
  • Pinned posts - Highlight important updates or announcements
  • Editor controls - Moderators can add, edit, and delete posts in real-time
  • Time-stamped entries - Each post shows when it was published

Ideal Use Cases

  • Live sporting events - Real-time game coverage, play-by-play updates
  • Breaking news - Ongoing coverage of developing stories
  • Elections - Live results and analysis as votes are counted
  • Product launches - Live coverage of announcements and reveals
  • Conferences & events - Real-time updates from on-site reporters

Basic Implementation

The simplest way to add Live Blog to your page requires just two steps:

Step 1: Load the Viafoura SDK

<script async src="https://cdn.viafoura.net/entry/index.js"></script>

Step 2: Add the widget

<div class="viafoura">
  <vf-live-blog></vf-live-blog>
</div>

Container ID Setup

Each Live Blog needs a unique container ID to keep content separate. You can set this in two ways:

Option 1: Meta tag (recommended)

<meta name="vf:container_id" content="P1002">

Option 2: Widget attribute

<vf-live-blog vf-container-id="P1002"></vf-live-blog>

Admin Configuration Requirements

IMPORTANT: A moderator or admin level user must load the page in order for the Live Blog to be initiated and configured. This is a one-time setup requirement per container ID.

Once an admin has initialized the Live Blog:

  • The widget becomes visible to all users
  • Authorized editors can create, edit, and delete posts
  • Posts appear in real-time to all viewers
  • No page refresh is required to see updates

Reply Feature

Replies are disabled by default in Live Blog. This widget is designed for one-way communication from publishers to audience, rather than threaded discussions. For two-way conversations, consider using the Conversations widget instead.

Required: Notification Tray

CRITICAL: The Live Blog widget requires the On-Site Notification Tray to be implemented on the page. The notification tray provides essential user interactions including login/signup, like, and other action buttons.

Failing to implement the Notification Tray will result in a broken user experience. Always include:

<vf-tray-trigger floating="true"></vf-tray-trigger>

Creating Live Blog Posts

Live Blog posts can be created through:

  • Viafoura CMS - Access the admin interface to add posts with rich formatting
  • Viafoura API - Programmatically create posts for automated workflows
  • On-page editor - Moderators can create posts directly on the live page

Best Practices

  • Initialize the Live Blog with an admin account before the event begins
  • Use clear, descriptive container IDs (e.g., "election-2026-live", "championship-game-11-04")
  • Pin important updates or announcements to keep them visible
  • Include timestamps for context, especially for long-running coverage
  • Test the widget with sample posts before going live
  • Ensure moderators are trained on the CMS before the event

Performance Considerations

  • Live Blog uses efficient WebSocket connections for real-time updates
  • Images and media should be optimized before uploading
  • Consider archiving very long Live Blogs (100+ posts) for performance
