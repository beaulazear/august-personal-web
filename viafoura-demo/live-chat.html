Implementing Viafoura Live Chat

Implementation Guide
November 4, 2026 Technical Documentation

What is Viafoura Live Chat?

Viafoura Live Chat (also called Community Chat) generates excitement and brings communities together for major events by creating dedicated chat windows. It delivers real-time, civil, and highly engaging social chat experiences with automated moderation capabilities.

Key Features

  • Real-time messaging - Messages appear instantly as users post them
  • Auto-scroll functionality - Chat automatically scrolls to show latest messages
  • Automated moderation - Built-in profanity filtering and spam prevention
  • Fixed height container - Maintains consistent page layout
  • User authentication - Requires login to participate in chat
  • Live event optimized - Designed for high-volume, fast-moving conversations

Ideal Use Cases

  • Live sporting events - Fan chat during games and matches
  • Breaking news - Real-time discussion of developing stories
  • Watch parties - Shared viewing experiences for TV shows, award ceremonies
  • Live streams - Companion chat alongside video content
  • Virtual events - Participant chat during webinars or conferences
  • Product launches - Community excitement during announcements

Basic Implementation

The Live Chat widget requires specific HTML structure with a height attribute:

Step 1: Load the Viafoura SDK

<script async src="https://cdn.viafoura.net/entry/index.js"></script>

Step 2: Add the widget with height

<div id="livechat-wrapper" style="height: 550px;" class="viafoura">
  <vf-livechat></vf-livechat>
</div>

Height Requirement

IMPORTANT: The height attribute is required and defines the overall height of the chat tool as it will appear on the page. Without a specified height, the widget may not display correctly.

Recommended heights:

  • Mobile: 400px - 500px
  • Desktop: 550px - 800px
  • Sidebar placement: 600px - 800px

You can use any custom value based on your layout needs, but ensure the height is sufficient for users to read and compose messages comfortably.

Container ID Setup

Each Live Chat needs a unique container ID to keep conversations separate. You can set this in two ways:

Option 1: Meta tag (recommended)

<meta name="vf:container_id" content="P1004">

Option 2: Widget attribute

<div id="livechat-wrapper" style="height: 550px;" class="viafoura">
  <vf-livechat vf-container-id="P1004"></vf-livechat>
</div>

Required: Notification Tray

CRITICAL: The Live Chat widget requires the On-Site Notification Tray to be implemented on the page. The widget includes several call-to-action buttons such as login/signup, post, reply, and others that rely on the notification tray.

Failing to implement the Notification Tray will result in a broken user experience. Always include:

<vf-tray-trigger floating="true"></vf-tray-trigger>

Live Chat vs. Conversations

Understanding when to use Live Chat versus Conversations:

Feature Live Chat Conversations
Use case Live events, real-time discussions Article comments, long-form discussion
Message flow Chronological stream, fast-moving Threaded replies, organized by topic
Display Fixed height container Variable height based on content
Lifespan Event duration (hours) Evergreen (days, months, years)

Moderation Features

Live Chat includes automated moderation tools to maintain civil discourse:

  • Profanity filtering - Automatically flags or removes inappropriate language
  • Spam detection - Prevents repetitive or automated messages
  • Rate limiting - Controls how frequently users can post
  • Manual moderation - Moderators can remove messages in real-time
  • User blocking - Ban disruptive users from participating

Best Practices

  • Initialize the chat before the event begins to ensure it's working properly
  • Set clear community guidelines visible to participants
  • Have moderators actively monitoring during high-traffic events
  • Test the height on both mobile and desktop to ensure good UX
  • Consider placing chat alongside video content for synchronized experiences
  • Archive or close the chat after the event concludes

Placement Options

  • Below content - Chat appears after article or video player
  • Sidebar - Chat in right or left rail alongside main content
  • Full-width - Dedicated chat page for major events
  • Embedded in video player - Integrated viewing experience
