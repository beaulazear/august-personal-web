Implementing Viafoura Polls

Implementation Guide
November 10, 2026 Technical Documentation

What is Viafoura Polls?

Viafoura Polls is a real-time polling widget that enables publishers to gather audience feedback, conduct surveys, and drive engagement. Polls are perfect for audience surveys, reader sentiment checks, product feedback, or event-based voting moments.

Key Features

  • Real-time results - Vote counts update instantly as users participate
  • Flexible authentication - Support for anonymous voting or login-required polls
  • Multiple question types - Single choice, multiple choice, and more
  • Quiz mode - Configure polls as quizzes with correct answers (contact CSM to enable)
  • Admin configuration - Moderators and admins can configure polls directly in the widget

Basic Implementation

The simplest way to add Polls to your page requires just two steps:

Step 1: Load the Viafoura SDK

<script async src="https://cdn.viafoura.net/entry/index.js"></script>

Step 2: Add the widget

<div class="viafoura">
  <vf-poll></vf-poll>
</div>

Container ID Setup

Polls use container IDs to keep poll data separate. Choose between two approaches:

Option 1: Article-level container ID (recommended for single polls)

<meta name="vf:container_id" content="P1006">

<div class="viafoura">
  <vf-poll></vf-poll>
</div>

Option 2: Widget-level container ID (required for multiple polls on one page)

<div class="viafoura">
  <vf-poll vf-container-id="poll-2026-election"></vf-poll>
</div>

<div class="viafoura">
  <vf-poll vf-container-id="poll-product-feedback"></vf-poll>
</div>

Configuration Parameters

Customize the poll widget with these parameters:

Parameter Type Description
vf-container-id String Unique identifier for the poll (required for widget-level implementation)

Admin Configuration

Important: A moderator or admin level user must load the page in order for the Poll to be initiated and configured. Upon authentication, a setup interface appears where you can:

  • Create poll questions
  • Add answer options
  • Set authentication requirements (anonymous vs. login required)
  • Configure as a quiz with correct answers (requires CSM enablement)

Use Cases

Polls are versatile and can be used for:

  • Audience surveys - "Which topic should we cover next?"
  • Reader sentiment - "Do you support this policy change?"
  • Product feedback - "Which feature is most important to you?"
  • Event voting - "Who do you think will win the championship?"
  • Quizzes - Test reader knowledge with correct/incorrect answers

Authentication Options

Polls support flexible authentication:

  • Anonymous voting - Users can vote without logging in (great for maximum participation)
  • Login required - Users must authenticate before voting (prevents duplicate votes)

Configure these options in the admin setup interface when creating your poll.

Best Practices

  • Use clear, concise question text
  • Provide balanced answer options
  • Consider whether anonymous voting or login is more appropriate for your use case
  • For multiple polls on one page, use widget-level container IDs
  • Refer to the Polls User Guide for comprehensive setup instructions
